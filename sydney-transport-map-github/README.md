# Sydney train network map

Interactive map of Sydney Trains, Metro, light rail and ferry routes with Greater Sydney LGA borders.

Once this repo is on GitHub with Pages enabled, the public link is:

`https://<your-username>.github.io/sydney-transport-map/`

That URL works on any phone or network.

## Local preview

```bash
python serve.py
```

Then open http://127.0.0.1:8765/

## Data

- **LGA borders** — ABS ASGS 2025 Local Government Areas (statistical approximation)
- **Routes and most stops** — OpenStreetMap
- **Line colours** — Transport for NSW brand palette
