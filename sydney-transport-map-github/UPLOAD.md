# Upload these files to GitHub Pages

1. Go to https://github.com/new
2. Name the repo `sydney-transport-map`
3. Set it to **Public**
4. Create the repository
5. Click **uploading an existing file**
6. Drag in everything in this folder (`index.html`, `app.js`, `styles.css`, `data`, `.nojekyll`, `.github`, `README.md`)
7. Commit
8. Open **Settings → Pages**
9. Under Build, choose **GitHub Actions**
10. After a minute the public map is:

`https://YOUR-USERNAME.github.io/sydney-transport-map/`
